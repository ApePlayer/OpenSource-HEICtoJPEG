HEIC to JPEG Converter Pro

Ein einfaches, schnelles Tool zur Batch-Konvertierung von HEIC-Bildern in das JPEG-Format unter vollständiger Beibehaltung der EXIF-Metadaten.

Funktionen / Features

Batch-Konvertierung: Konvertiere ganze Ordner mit einem Klick.

Metadaten-Erhalt: Alle EXIF-Daten (Datum, Standort, Kamera-Infos) bleiben erhalten.

Modernes GUI: Einfache Bedienung mit Ladebalken und Abbruch-Funktion.

Zweisprachig: Unterstützt Deutsch und Englisch.

Portable: Keine Installation erforderlich.

Systemanforderungen / System Requirements

Windows 10 / 11

Keine zusätzliche Software oder Python-Installation nötig (Portable .exe).

Bedienungsanleitung / How to use

Deutsch:

Starten Sie die HEIC-Converter-Pro.exe.

Wählen Sie oben links Ihre bevorzugte Sprache.

Klicken Sie auf "Starten".

Wählen Sie den Quellordner (mit den .heic Dateien).

Wählen Sie den Zielordner (wo die .jpg Dateien gespeichert werden sollen).

Warten Sie, bis der Ladebalken abgeschlossen ist. Fertig!

English:

Run the HEIC-Converter-Pro.exe.

Select your preferred language in the top-left corner.

Click "Start".

Select the source folder (containing .heic files).

Select the destination folder (where .jpg files should be saved).

Wait for the progress bar to finish. Done!
